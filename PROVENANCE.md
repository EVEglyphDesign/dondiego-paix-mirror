# Provenance

This repository is a **community, non-commercial mirror** of the public website of
**Fundación Comunitaria Don Diego A.C.**
(https://fundacioncomunitariadondiego.com/), captured on 2026-08-17 for the purpose of hosting an educational extension page (`/paix/`) built
by EVEglyphDesign in the same visual style as the Foundation's own site.

- Source: https://fundacioncomunitariadondiego.com/ and https://fundacioncomunitariadondiego.com/en/
- All copy, images, videos, and the Pathwell theme customisation on this mirror are
  the property of Fundación Comunitaria Don Diego A.C. and its contributors.
- Only `/paix/`, `/en/paix/`, and the top-of-page provenance banner are original
  contributions by EVEglyphDesign.
- No revenue is generated from this mirror. No donations are collected here; the
  donation flow (`/donar/`) links back to the Foundation's own systems.
- On written request from the Foundation, this mirror will be taken down.

Contact: dondiegofoundation@gmail.com (Foundation), EVEglyphDesign (mirror steward).
